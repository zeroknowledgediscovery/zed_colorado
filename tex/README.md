# ZeBRA--genomics manuscript

This directory contains the canonical theory + empirical manuscript for the ZeBRA--genomics likelihood-ratio paper.

## Canonical build

The single canonical document is:

```text
zebra_genomics_boundary_theorem_empirical.tex
```

Build it with:

```bash
cd tex
./build_full_manuscript.sh
```

The resulting PDF contains both the main manuscript and the complete Supplementary Material at the back. There is no separate supplementary document.

The canonical narrative is modular and uses the external BibTeX bibliography `zebra_genomics_references.bib` with the standard `IEEEtran` bibliography style. The back-of-document Supplementary Material contains the auxiliary proofs and the full robustness/diagnostic analyses.

The older `zebra_genomics_boundary_theorem.tex`, `empirical_section_update.tex`, and bundled historical drafts are not part of the canonical build.

## Empirical scope

The current manuscript is intentionally restricted to one phenotype:

```text
FILD or FILA ADJUDICATED
```

The two sparse nonfibrotic endpoints explored during analysis development are not part of the current manuscript argument. The biological genomic focus is the MUC5B rs35705950 channel, with the broader selected genomic panel used for global incremental-prediction analyses.

## Main evidence hierarchy

The main document now uses four figures.

1. **Global prediction and feature attribution.** FILD/FILA held-out AUC, paired incremental genomic value, paired AP/Brier/log-loss changes, and repeated-split SHAP stability. The ZeBRA risk score is rank 1 in every combined-model split; the rs35705950 MUC5B genotype indicator is the most recurrent genomic feature.
2. **Distinct channels.** ZeBRA does not reconstruct MUC5B carrier state, despite the strong disease association of MUC5B.
3. **Localized complementarity.** Local nested-model information and effect-size analyses show where residual MUC5B information is concentrated along the ZeBRA axis and where the clinical channel overtakes it in the extreme tail.
4. **Direct cross-fitted likelihood-ratio evidence.** The main theorem-data figure shows the actual cross-fitted clinical `Lambda_Z` and residual `Lambda_{G|Z}` channels, empirical high-probability residual scales `bhat_delta`, and localization of genomic-induced decision changes near the clinical LR boundary.

The direct LR analysis is the primary empirical test of the finite-stage theorem. Boundary rescue, stringent operating points, the full LR estimator-sensitivity grid, calibration, adjudicated-negative diagnostics, and the ROC-hull diagnostic are retained in the Supplementary Material.

## Figure implementation

The manuscript figures are generated with PGFPlots/TikZ from the canonical analysis results at compile time. `empirical_figures.tex` loads the data definitions, historical figure macros used for supplementary material, and the current FILD-focused main-text figure overrides.

The actual cross-fitted LR channel curves are read from the moving-window summaries generated by the direct likelihood-ratio analysis. They are now explicitly displayed in the main manuscript rather than represented only by numerical summaries.

## Theory hierarchy

The central theorem is finite-stage boundary localization. At a fixed clinical-history stage, the finite-stage stochastic residual scale is sufficient for the high-probability boundary-localization result; neither A1-U nor A2 is required.

A1-U and A2 are introduced only for the separate conditional sequential tail-extension theorem. A1-U requires a residual-genomic bound uniform over clinical-history length, while A2 assumes that arbitrarily strong positive clinical evidence is attainable on rare trajectories. The Colorado analysis does not prove either assumption.

The empirical analysis instantiates the exact observable score-level factorization

```text
Lambda_Z,G = Lambda_Z * Lambda_G|Z
```

and estimates the score-level empirical residual scale. It does not establish full-history sufficiency, a universal genome-wide bound, or mathematical unboundedness of clinical evidence.

## Supplementary Material

The Supplementary Material is included after the conclusion in the same PDF. It contains:

- proofs of auxiliary theoretical results;
- detailed repeated-split SHAP stability;
- direct-LR estimation details and the nine-specification sensitivity analysis;
- local diagnostic p-values and moving-window values;
- matched-FPR MUC5B rescue and adjudicated-negative diagnostics;
- stringent operating-point comparisons;
- calibration diagnostics;
- the supporting ROC-hull analysis; and
- explicit scope statements for the empirical likelihood-ratio result.

It is written as scientific supplementary material and does not enumerate computational result filenames or repository provenance paths.
